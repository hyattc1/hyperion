# hyperion design

A millisecond-budget poker bot for a timed bot-building format, called the target format below; its
constraints are stated plainly under "Hard constraints". This document is the build contract.

## Intent

Win tables, not poker. Scoring is relative: eight bots per table, points by finishing position plus ICM, averaged
over 10,000 tables, six tournaments weighted 1..6. The field is bots built in an hour. The bot that wins is the
one that never crashes, never times out, plays the short-stack phase correctly, and exploits the archetypes that
one-hour bots always are.

## Hard constraints (the target format)

- Python only. Provided `Agent` interface, unknown signature until build start.
- 1 ms per decision. Timeout or exception auto-folds (checks if possible).
- 100 MB submission cap, sandboxed, no network, state reset per table, opponents anonymized.
- 8-max SNG: 2,000 chips, blinds 10/20 rising every 25 hands, 200-hand cap, ICM at cap.
- Variant secret until build; a later round may use a different variant.
- Allowed third-party packages unknown. Decision path is stdlib only.

## Goals

1. Submit a legal, crash-proof bot within 15 minutes of seeing the kit.
2. Have every decision under 0.3 ms in pure Python on a slow laptop (3x margin on 1 ms).
3. Regenerate every table from parameters (rank order, hole-card count, hand-category order) in under 5 minutes.
4. Measure, not guess: a local 8-max SNG harness with a bestiary of likely opponents and confidence intervals.
5. Rehearse: timed drills against a catalog of plausible variants with a fake kit.

## Non-goals

- Full-game CFR blueprints, neural nets, real-time search. Ruled out by the millisecond and the secret variant.
- Pretty output, web UIs.

## Anti-goals

- Any strategy code that imports the kit directly. Everything goes through an adapter.
- Any table that cannot be regenerated by `tools/gen_tables.py`.
- Any decision path that allocates big objects or does Monte Carlo at decision time.

## Architecture

```
hyperion/
  core/      cards, evaluator, equity generator, ICM. Parameterized by Rules.
  strategy/  safe wrapper, opponent profiler, preflop charts, push/fold, postflop rules, hero bot.
  sim/       8-max SNG engine, blind schedule, scoring, bestiary bots, runner with CIs, latency profiler.
  drills/    fake kits (several plausible Agent signatures), variant mutations, timed drill script.
tools/       table generation CLI.
tables/      generated artifacts (json). Checked in for the default rules; regenerated per variant.
tests/       pytest.
```

### Shared contracts (`hyperion/core/types.py`)

- `Rules`: hole_cards, board_sizes per street, rank_order (permutation), suit count, hand_category_order,
  wild/bounty hooks. Default = standard NLHE.
- `Card`: int 0..51 (rank*4+suit) under the *canonical* ordering; `Rules.rank_order` remaps display ranks to
  canonical strength so the evaluator never changes.
- `Observation`: kit-agnostic view of one decision: hole, board, street, my seat, button, stacks[], bets[],
  in_hand[], pot, to_call, min_raise, max_raise, legal actions, blind level, hand number, players remaining,
  action history for this hand.
- `Action`: kind in {FOLD, CHECK, CALL, RAISE} with amount (total bet size), plus `.clamp(obs)`.
- `Bot` protocol: `new_table(rules, seat, n_players)`, `act(obs) -> Action`, `hand_end(result)`.

### Decision budget

Soft deadline 0.5 ms measured with `time.perf_counter`. The wrapper returns the safe action (check else fold)
on any exception or budget overrun, and clamps raise sizes to legal bounds.

## What is left to the builder

Table formats, exact bestiary parameters, drill timings. Record each call in `docs/decisions.md`.

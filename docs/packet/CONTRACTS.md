# CONTRACTS: the API card

Generated by `python tools/apicard.py` from the code. Do not edit by hand.

Cards are ints `rank*4 + suit`, rank 0 = deuce ... 12 = ace, suits c d h s = 0..3. `parse_cards('Ah Kd')` and `cards_str(...)` convert. Strategy never sees a kit; one `Adapter` subclass translates both ways. `Action.raise_to(amount)` is a raise-TO total for this street, never an increment. `obs.pot` excludes this street's bets; `obs.total_pot` includes them. `obs.position()` is 0 for first to act postflop, n-1 for the button; `obs.stack_bb` is my stack in big blinds.

## Bot protocol

`new_table(rules, seat, n_players)` · `act(obs) -> Action` · `hand_end(result: HandResult)`

## Adapter (the only code written on the night)

- `__init__(self, bot: 'Bot', rules: 'Rules | None' = None)`: Initialize self.  See help(type(self)) for accurate signature.
- `decide(self, native: 'Any') -> 'Any'`
- `from_action(self, action: 'Action', obs: 'Observation', native: 'Any') -> 'Any'`
- `hand_end(self, hand_no: 'int', delta: 'int', n_players: 'int | None' = None, history=None, deltas=None, final_stacks=None, showdown=None, board=()) -> 'None'`: The hand is over; pass whatever the kit's hand-end signal has.
- `native_safe(self, native: 'Any') -> 'Any'`: The kit's own check-if-possible-else-fold, used when translation itself blows up.
- `start(self, seat: 'int', n_players: 'int', rules: 'Rules | None' = None) -> 'None'`
- `to_observation(self, native: 'Any') -> 'Observation'`
- `with_history(self, obs: 'Observation') -> 'Observation'`: obs with the history the bot reads: the kit's log, or the one rebuilt from the states (history_source).

Reference adapters for four fake kits live in `hyperion/drills/adapter.py` and `hyperion/drills/fakekits/*/RUBRIC.md` lists the gotchas each one covers.

`history_source` says what the kit shows of the betting: `"log"` (its full action log, passed as `history`), `"partial"` (some actions, merged), `"bets"` (none). For the last two `decide` rebuilds the hand's log from the states (`hyperion/drills/infer_history.py`: each seat's in-hand flag, stack and bet between our decisions, replayed through the betting order; every entry happened; a state it cannot settle ends the log for the hand). `hand_end` adds our last reply and the folds after it that the kit's `deltas` / `final_stacks` / `showdown` settle; with only our chip change it holds the hand end for the next hand's first state (`defer_hand_end`, `hold_all`). The sim seat that sees what such a kit gives is `InferSeat(bot)`.

## The ship bot (`hyperion/ship.py`, the switch)

`SHIP = 'composite'`, `DIALS = {}`. The submission entry builds it with `hyperion.ship.make_bot()`; `tools/pack.py` records the bot and dials it packed in the package's copy of that file and `tools/gate.py` pairs the zip against the same bot in-sim; `tools/latency.py` and `python -m hyperion.sim --field <field>@ship` measure it. Every tool takes `--bot NAME` and `--dials JSON`; `--bot hero` restores Hero, `--bot cheap` is Stage 2's Hero.cheap(). Names: `hybrid3_x`, `hybrid3`, `hero`, `cheap`, `composite`.

hybrid3_x (and the composite's base) is rival 3's decision core plus the exploit layer behind Hero's shell (adapter, Rules, rank remap, variant decisions, SafeBot). The core makes about 97% of plain hold'em decisions; Hero plays the 14 tables the core cannot represent (short deck, lowball, wild cards, hi/lo, two boards, must-use, three or more hole cards, fixed limit, bounties, exposed cards) and the straddle preflop. So Hero's Config keys move hybrid3_x only there: on hybrid3_x they are written `hero.<key>`, and a bare Hero key is an error.

The composite (`hyperion/compose/`, the ship bot since the decisions entry "Composite bot") plays that base preflop and Hero postflop and when it faces a raise short (under 20 bb effective, four or more players), with the layer in front of both; with no dials it is the measured composite (`hyperion.compose.bot.SHIP_DIALS`: the route, `exploit.bet_min_fold` 0.4, `hero.postflop.call_margin` 0.2). Its dials: `route` ("section=donor,..."), `r3.<name>` for the base's core, `exploit.<field>`, `hero.<key>` (the hero member and the base's fallback Hero, as on hybrid3_x), `cheap`, `light`.

## Commands

- Run tests (the day): `python -m pytest -q`
- The night's tests: adapter, conformance, pack, switch and templates (about a minute at load 18): `python -m pytest -q -p no:cacheprovider -m night`
- The ship bot (see the switch) vs realistic field, strict 1 ms: `python -m hyperion.sim --tables 300 --seed 11 --mode strict --field realistic@ship`
- Same, duplicate-dealt (seating luck cancels): `python -m hyperion.sim --tables 40 --rotate --seed 11 --mode strict --field realistic@ship`
- A window's recipe, measured (prompt 06: paired against the bot we ship, the night field, tonight's rules): `python tools/climb_accept.py --stages window --base '<kept>' --cand '<kept>+passive' --rules submission/rules_tonight.json --workers 4`
- A recipe or dials in a sim run (same seed without it is the before): `python -m hyperion.sim --tables 300 --seed 11 --mode model --field realistic@ship --dials passive`
- Keep dials in the switch / print it: `python -m hyperion.ship --set survival+passive   |   python -m hyperion.ship`
- Hero instead (the base until 2026-11-01): `python -m hyperion.sim --tables 300 --seed 11 --mode strict --field realistic   (and --bot hero on pack, gate, latency)`
- Pack the upload (records the bot; --bot cheap at Stage 2): `python tools/pack.py --entry submission/<entry>.py --out dist/ --extra submission/adapter.py submission/rules_tonight.json`
- Gate the zip against the same bot in-sim: `python tools/gate.py dist/submission.zip --kit a|b|c|d --tables 100 --rules rules_tonight.json`
- Decision latency of the ship bot: `python tools/latency.py --n 2000 --rules rules_tonight.json`
- Regenerate every table for a variant: `python tools/gen_tables.py --rules rules_tonight.json --out tables/`
- List variant presets / write a rules JSON: `python -m hyperion.drills.variants --list   |   --rules NAME --out rules_NAME.json`
- Timed drill against a fake kit: `python -m hyperion.drills.run --variant NAME --kit a|b|c|d --seed 1`
- The rebuilt action log: precision and recall on sim tables / what it wins back: `python -m hyperion.drills.infer_eval --check 20 --fields realistic --bots ship   |   --fields realistic --bots hero --cases nolog,infer,full --seeds 50 --rotate`

## Entry points

- `hyperion.ship.make_bot(name=None, dials=None)` -> the bot we ship (SHIP with DIALS; what the entry builds). `make_bot('cheap')` = `Hero.cheap()`.
- `hyperion.strategy.hero.make_bot(config=None)` -> Hero (SafeBot-wrapped). `Hero.cheap()` -> the 15-minute fallback.
- `hyperion.strategy.tables.load(tables_dir)` -> preflop tables; `hyperion.strategy.pushfold.load_pushfold(tables)`.
- `hyperion.core.eval.evaluate(cards)` -> int strength, higher is better, 5 to 8 cards.
- `hyperion.core.icm.icm_equity(stacks, payouts)` -> expected points per seat (never call in act()).
